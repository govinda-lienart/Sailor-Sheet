================================================================================
🔄 DATA FLOW & TRANSACTION PROCESS
================================================================================

1. 👤 User Access
   └── Browser → Flask Web Server (app.py)

2. 📝 Form Loading
   ├── Load Google Sheets list → sheets_manager.get_available_sheets()
   ├── Load funds → app.get_funds_from_json()
   ├── Load accounts → app.get_accounts_from_json()
   └── Load categories → app.get_categories_from_json()

3. 📊 Sheet Selection
   └── AJAX → app.get_worksheets() → sheets_manager.get_worksheets_from_sheet()

4. 📤 File Upload (Optional)
   └── AJAX → app.upload_file() → file_upload_manager.handle_web_upload()

5. 💾 Transaction Submission
   ├── Form validation
   ├── Regular transaction → sheets_manager.add_transaction_to_selected_sheet()
   └── Interbanking transfer → Dual entries in Master Ledger A & B

6. ✅ Success Confirmation
   └── Redirect to thank_you page
