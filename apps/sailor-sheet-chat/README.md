# ⛵ Sailor Sheet Chat

A simple React chatbot for the accounting software.

## Features

- **Blue sailboat icon** that expands into a chat window
- **Hardcoded responses** for testing
- **Modern, professional design**
- **Responsive layout**

## Quick Start

1. **Install dependencies:**
   ```bash
   cd apps/sailor-sheet-chat
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm start
   ```

3. **Open your browser:**
   - Go to `http://localhost:3000`
   - Click the blue sailboat icon in the bottom-right corner
   - Try typing: "hello", "help", "transaction", "fund", "account"

## Test Commands

Try these messages to test the hardcoded responses:
- "hello" or "hi"
- "help"
- "transaction"
- "fund"
- "account"
